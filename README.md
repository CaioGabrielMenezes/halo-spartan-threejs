# Halo Spartan — Three.js

Cena 3D feita com [Three.js](https://threejs.org/) mostrando a armadura Mk V do Halo com animações criadas no código.

**Ver online:** https://caiogabrielmenezes.github.io/halo-spartan-threejs/

## Animações

Use os botões na parte de baixo da tela para trocar de animação:

- **Alerta** — postura de combate, olhando ao redor
- **Andar** — caminhada de soldado no lugar
- **Saudação** — continência militar
- **Golpe** — golpe corpo a corpo com passo à frente

Arraste com o mouse para girar a câmera e use a rodinha para dar zoom.

## Como rodar

Precisa do [Node.js](https://nodejs.org/) instalado.

```bash
npm install
npm run dev
```

Depois abra o endereço que aparecer no terminal (normalmente http://localhost:5173/halo-spartan-threejs/).

> No PowerShell do Windows, se aparecer erro de "execução de scripts", use `npm.cmd run dev`.

## Créditos do modelo

O modelo 3D é o [Halo Mk V Model](https://sketchfab.com/3d-models/halo-mk-v-model-ff8a4e4f9d1f4fdeb3a1d887f6f70dae), criado por [Pep0398](https://sketchfab.com/Pep0398) no Sketchfab e licenciado sob [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/). As animações não vêm do modelo: foram feitas no código deste projeto.
